English

Kuu3D è un visualizzatore 3D per iPhone e iPad. Supporta USDZ, OBJ, STL, glTF / GLB, PLY e altri formati. Apri i file direttamente dall'app File, tramite AirDrop o dal menu Condividi di altre app.

Domande frequenti
Apertura file
Quali tipi di file posso aprire?

Kuu3D supporta USDZ / USD, OBJ, STL, glTF / GLB e PLY (nuvole di punti). Puoi aprire file dall'app File o dal menu Condividi di altre app. È supportato anche AirDrop.

Ci sono dati di esempio?

Nella schermata senza nessun modello aperto, tocca «Apri esempio» per provare una mesh (la Luna) o una nuvola di punti (un nodo a trifoglio). Gli esempi non vengono aggiunti alla libreria.

I file impiegano molto tempo per aprirsi.

I modelli di grandi dimensioni richiedono più tempo per caricarsi. Il tempo trascorso viene mostrato: attendi finché il modello appare. OBJ è un formato testuale e impiega particolarmente a lungo. Convertire la stessa forma in STL o GLB è molto più veloce.

Non riesco ad aprire un file di grandi dimensioni.

Se un file è troppo grande per la memoria del dispositivo, prima dell'apertura appare un messaggio di conferma. In linea di massima, i modelli superiori a circa 500 MB (circa 10 milioni di triangoli per STL) potrebbero non aprirsi. Riduci il numero di poligoni nel tuo software 3D o dividi il modello.

Il file è troppo pesante o voglio alleggerirlo.

L'app web gratuita «Sirppi3D Web» riduce il numero di triangoli di un file 3D. Il pulsante «Abbina dimensioni Kuu3D» imposta la dimensione ottimale per un'apertura fluida in Kuu3D. Funziona interamente nel browser: i tuoi file non vengono mai caricati.

Apri Sirppi3D Web

L'app si è chiusa durante l'apertura di un file grande.

Se il dispositivo esaurisce la memoria, l'app può chiudersi. Al prossimo avvio, verrà mostrato il nome del file che era aperto. Quel file non si aprirà automaticamente e non verrà creata alcuna miniatura. Riprova dopo aver alleggerito il modello.

Ho inserito un file pesante direttamente nella cartella Kuu3D tramite l'app File.

L'app potrebbe chiudersi una volta, ma non continuerà a farlo ripetutamente. L'elenco legge solo nomi e dimensioni, e non vengono create miniature per i file grandi. All'apertura appare una verifica della memoria. Se l'app si chiude durante il caricamento, al prossimo avvio riceverai una notifica e il file non si aprirà automaticamente.

Posso aprire file .3mf o .fbx?

Non supportati nella versione attuale.

Visualizzazione & Controlli
Il modello sembra essere capovolto.

Alcuni modelli hanno la direzione delle facce invertita (normali). All'apertura appare un messaggio di conferma. Prova ad attivare/disattivare Z-Up o correggi il modello in un altro software 3D.

Voglio cambiare l'unità di misura.

Tocca le dimensioni nella barra informazioni per scegliere tra mm, cm, m o pollici. La scelta viene salvata per ogni file.

Le dimensioni mostrano «stimato».

L'unità viene rilevata automaticamente dal formato del file. Tocca e scegli l'unità corretta: l'etichetta «stimato» scomparirà e la scelta verrà salvata.

Voglio cambiare il MatCap (aspetto del materiale).

Tocca il pulsante MatCap nella barra degli strumenti per passare tra i 6 MatCap e la vista silhouette.

Voglio cambiare lo sfondo.

Usa il pulsante sfondo nella barra degli strumenti per passare tra 4 sfondi: Cielo, Tramonto, Notte e Sakura.

Voglio usare la visualizzazione wireframe.

Usa il pulsante wireframe nella barra degli strumenti per sovrapporre le linee della mesh. Puoi scegliere tra 3 colori.

Il modello appare piccolo e spostato verso il bordo dello schermo.

Tocca due volte lo schermo per adattare automaticamente l'intero modello nella vista.

Voglio inclinare il modello.

Ruota due dita come se disegnassi un cerchio e il modello si inclinerà attorno alla direzione di visione. Tocca due volte per tornare all'orientamento originale.

Cos'è Z-Up?

Diversi software 3D usano Y o Z come asse verticale. Se il modello appare di lato, attiva il pulsante Z-Up nella barra degli strumenti.

Voglio cambiare la direzione della luce.

Tocca il pulsante luce nella barra degli strumenti: sullo schermo apparirà un cerchio bianco. Trascina all'interno del cerchio per cambiare la direzione della luce. Il piccolo punto indica la posizione della luce. Quando è pieno e bianco, la luce è davanti al modello; quando è solo un contorno, la luce è dietro. Il cerchio appare sempre al centro del modello e svanisce automaticamente. Tocca di nuovo il pulsante luce per uscire. La direzione viene mantenuta e torna alla posizione predefinita quando si passa al MatCap o al wireframe.

La rotazione automatica si interrompe a metà.

Nella versione gratuita, la rotazione automatica si interrompe dopo mezzo giro (180°). Sblocca Tutte le funzionalità per mantenerla in rotazione.

I pulsanti sono scomparsi durante la rotazione automatica.

Durante la rotazione automatica, i pulsanti sullo schermo si nascondono automaticamente dopo circa 2 secondi. Tocca lo schermo per mostrarli di nuovo; si nascondono di nuovo circa 2 secondi dopo aver sollevato il dito. Puoi disattivarlo nelle Impostazioni.

Libreria & Gestione dati
Mi è stato detto che la libreria è limitata a 3 elementi.

La versione gratuita può memorizzare fino a 3 elementi nella libreria. Sblocca Tutte le funzionalità per uno spazio illimitato. Puoi anche eliminare elementi esistenti per importarne di nuovi nella versione gratuita.

Cosa succede al mio file quando lo importo nella libreria?

Il file viene copiato nella cartella Kuu3D. Il file originale rimane dov'era.

Le miniature della libreria non appaiono.

Le miniature non vengono create per i file di grandi dimensioni, per evitare problemi di memoria durante la generazione. Al loro posto, vengono mostrate le dimensioni del file sotto il nome e il formato in alto a destra.

I dati della mia libreria sono scomparsi dopo aver cambiato dispositivo.

I dati della libreria sono memorizzati sul tuo dispositivo. Il backup su iCloud non è attualmente supportato. Conserva i tuoi file importanti come originali.

Impostazioni
I colori o le texture del modello non vengono applicati.

«Carica colori» nelle Impostazioni è disattivato. Quando è attivo, i modelli vengono visualizzati con le loro texture, colori dei vertici e materiali. La modifica ricarica automaticamente il modello aperto. I colori delle nuvole di punti vengono sempre applicati.

Acquisto
È un acquisto una tantum?

Sì, è un acquisto una tantum (non un abbonamento). Acquista una volta e usa senza costi aggiuntivi. La Condivisione in famiglia non è supportata.

Cosa ottengo con Sblocca tutte le funzionalità?

Puoi memorizzare elementi illimitati nella libreria e mantenere la rotazione automatica. Tutte le altre funzionalità sono gratuite.

Il mio acquisto è scomparso dopo aver cambiato dispositivo o reinstallato.

Tocca «Ripristina acquisto» nella schermata Impostazioni. Se usi lo stesso ID Apple, il tuo acquisto verrà ripristinato.

Privacy & Altro
Raccogliete informazioni personali o i miei dati?

No. Non raccogliamo alcun dato. I file che apri vengono memorizzati solo sul tuo dispositivo e non vengono mai inviati da nessuna parte. (Solo il processo di acquisto è gestito dall'App Store di Apple.)

Posso riprodurre animazioni?

Non supportato nella versione attuale.

Voglio salvare uno screenshot.

L'app non ha una funzione screenshot. Usa il metodo integrato di iOS (pulsante laterale + pulsante volume).

Posso usarlo su iPad?

Sì. Funziona sia su iPhone che su iPad, e su iPad sia in modalità verticale che orizzontale.
